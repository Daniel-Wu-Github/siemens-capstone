## 1. Demand per day (per position)

| Input | Definition |
| --- | --- |
| history | average replenishment quantity per day from the transfer log |
| schedule | planned production quantity over the next 30 days / 30, only when the BOM maps the part to exactly one position |
| observed | snapshot depletion per day, weight 0 (current stock only) |

`demand = (2 x history + 1 x schedule) / (2 + 1)`

- Default weights are history 2 : schedule 1 (changed from 1 : 1 on 2026-11-04 at the user's explicit direction). Settings expresses the two as one history share, so raising one lowers the other.
- If `abs(schedule - history) / history x 100 > divergence`, history is dropped and `demand = schedule`. The default divergence is 1000%, which switches the override off in practice; set it to 50 to restore the earlier rule. The check is skipped when history is 0.
- If only one input exists, use it. If none exists there is no forecast.

## 2. Hours to minimum

`hours_to_min = max(0, available - min) / demand x 24`

`available` is the latest dated snapshot Live Value.

## 3. Alert tiers

| Tier | Condition | Delivery |
| --- | --- | --- |
| Alert (reactive) | `available <= min` | email / Teams / webhook |
| Predicted | `hours_to_min <= lead_hours + safety_hours` | email / Teams / webhook |
| Watch | `hours_to_min <= watch_hours` | dashboard only |

Defaults: `lead_hours` 3 (stocked and fab, placeholder), `safety_hours` 24, `watch_hours` 72, divergence 1000% (override off; the earlier default was 50%). A position with `min = 0` is treated like any other.

## 4. Suggested quantity

`suggested_qty = ceil(max - (available - demand x lead_hours / 24))`

The result is never below 0. It assumes the refill goes up to Max (placeholder: the log shows a median target of 35% of Max).

## Worked example (invented numbers)

available 35, min 20, max 90, history 8/day, schedule 10/day, lead 3 h.
1. Demand = (2 x 8 + 1 x 10) / 3 = 8.67/day (history is not dropped: divergence 1000%).
2. hours_to_min = max(0, 35 - 20) / 8.67 x 24 = 41.5 h.
3. 41.5 > 3 + 24 = 27, so not Predicted. 41.5 <= 72, so Watch.
4. suggested_qty = ceil(90 - (35 - 8.67 x 3 / 24)) = ceil(56.08) = 57.
